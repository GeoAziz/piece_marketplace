# Kenya Land Marketplace

This repository contains the Kenya Land Marketplace project. The first three folders under the repo root (`copilot/`, `mds/`, `docs/`) are the AI control and specification plane. The rest are execution artifacts.

Key locations
- `copilot/` — AI governance, plans, and verification artifacts.
- `mds/` — machine-readable specifications (data models, APIs, badges, permissions).
- `apps/` — frontend applications (placeholder for now).
- `services/` — backend microservices (placeholder for now).

Workflow
- Follow the PLAN → CODE → VERIFY → REFINE loop in `copilot/prompt.md` before implementing production code.
