Verification badges — semantics and required evidence

Badge: EvidenceSubmitted
- Meaning: Uploader has attached one or more evidence documents to the listing.
- UI language: "Evidence submitted by seller. Evidence not reviewed."

Badge: EvidenceReviewed
- Meaning: An admin (or trusted process) has inspected the provided evidence and recorded a review.
- UI language: "Evidence reviewed — not a legal confirmation. See review details for rationale."
- Required evidence: at least one document of type title or survey_plan, or a combination the reviewer accepts.

Badge: TrustedSignal
- Meaning: Multiple independent evidence sources corroborate listing claims (conservative signal).
- UI language: "Multiple evidence sources corroborate listing details — not a legal guarantee."

Badge: Suspicious
- Meaning: Evidence or metadata triggered automated or manual flags; users should proceed with caution.
- UI language: "This listing has been flagged as suspicious. Contact support or request more evidence."
